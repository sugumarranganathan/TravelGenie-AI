# 🌍 TravelGenie AI

An Intelligent Multi-Agent Travel Planning Assistant built using Groq LLM and Gradio.

---

## 📌Project Overview

TravelGenie AI is an AI-powered travel planning assistant that helps users create personalized travel plans. The system uses a multi-agent architecture where each AI agent performs a specific task to generate a complete travel experience.

The application demonstrates how multiple AI agents can collaborate to analyze user requirements, research destinations, estimate travel budgets, generate itineraries, and review the final travel plan.

---

##  Features

- 🤖 Multi-Agent AI Architecture
- 🗺 Travel Planning
- 🔍 Destination Research
- 💰 Budget Estimation
- 📅 Day-wise Itinerary Generation
- ✅ Travel Plan Review
- 🧠 Shared Memory Between Agents
- 💬 Interactive Gradio Interface
- ⚡ Powered by Groq LLM
